# PolitiScope v1.3

Ajouts: horizon de projections jusqu’en 2040, couverture élargie de 39 pays occidentaux, calendrier indicatif jusqu’en 2040, et module Horizon 2040.

Les années lointaines sont des horizons de scénario. Elles ne constituent pas des dates électorales officielles. Les projections à long terme affichent N/D si les données de sondage sont insuffisantes et augmentent explicitement l’incertitude avec l’horizon.

Sources institutionnelles consultées pour la conception du calendrier: Elections Canada, Service-Public France, GOV.UK/House of Commons Library, Bundeswahlleiterin.
