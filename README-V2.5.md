# PolitiScope V2.5 — Historical Mode

## Nouveautés
- Historical Mode pour parcourir les trois derniers scrutins nationaux comparables.
- Structure de données pour participation et mesures externes d'intégrité.
- Aucune note de « fiabilité » inventée par PolitiScope.
- PEI : score externe par scrutin lorsqu'il est disponible.
- V-Dem : indicateurs externes avec incertitude méthodologique.
- Les valeurs non vérifiées restent explicitement `to_complete`.

## Méthode
La participation est définie selon International IDEA comme le total des votes exprimés divisé par les électeurs inscrits. La base privilégie les autorités électorales nationales comme sources primaires. Les comparaisons historiques privilégient la même famille de scrutin.

## Prochaine passe de données
Compléter méthodiquement les 39 pays × 3 scrutins, avec date, type, participation, source primaire, et mesures d'intégrité externes disponibles.
