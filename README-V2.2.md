# PolitiScope V2.2

## Nouveautés
- PolitiScope Index transparent : six signaux séparés, sans score global ni classement politique.
- Calendrier électoral occidental enrichi 2026–2040.

Les dates futures peuvent changer en cas d’élection anticipée, dissolution ou modification légale.
