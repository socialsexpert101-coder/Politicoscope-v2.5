# PolitiScope V2.1 — Coalition Lab

- Axe analytique à cinq zones : extrême gauche, gauche, centre, droite, extrême droite.
- Coalition Lab interactif avec sélection multi-acteurs.
- Cohésion mécanique, amplitude idéologique et centre de gravité.
- Compte séparé des coopérations documentées et scénarios hypothétiques.
- Garde-fou : les zones « extrêmes » du modèle ne constituent pas une classification factuelle; toute classification externe doit être sourcée et datée.
- Interface mobile Android.
