# PolitiScope v1.2

Version mobile/PWA améliorée du prototype PolitiScope.

## Nouveautés
- Cockpit avec métriques, signal du jour et top intentions.
- Comparaison des variations lorsque plusieurs observations existent.
- Stress-test d'alliance entre deux leaders, explicitement hypothétique.
- Bouton d'installation PWA lorsqu'Android/Chrome expose le prompt.
- Méthodologie et qualité du flux plus visibles.
- Interface responsive renforcée pour smartphone.

## Données
Le dépôt reste en mode `demo` tant que des sources réelles n'ont pas été configurées. Les valeurs `demo:true` ne doivent pas être publiées comme sondages réels.

## Publication GitHub Pages
Le workflow `.github/workflows/pages.yml` publie le contenu statique. Le workflow `.github/workflows/daily-update.yml` est prévu pour la veille quotidienne.
